# Daniel Rueda — Portfolio

Portfolio personal de **Daniel Rueda** — Programador Junior (C#, .NET, SQL, JavaScript, PHP). Diseño en blanco y negro, sin frameworks ni dependencias.

**Demo local:** abre `index.html` en el navegador. Sin build.

## ✨ Qué incluye

- **Sobre mí** con foto circular
- **Habilidades** en gráfico horizontal con barras y detalle al hover
- **Proyectos** en carril horizontal con flechas — cada tarjeta enlaza a su repo:
  - [KahootInspired](https://github.com/danielruedaaa/KahootInspired) · C# / .NET 8 + Sockets
  - [RollTheDie](https://github.com/danielruedaaa/RollTheDie) · C# WinForms + GDI+
  - [BibliotecaDigital](https://github.com/danielruedaaa/BibliotecaDigital) · PHP + MySQL / PDO
  - [F1Hub](https://github.com/danielruedaaa/F1Hub) · JavaScript + OpenF1 API
- **Trayectoria** como línea de tiempo animada al hacer scroll
- **Contacto** con formulario `mailto:`, botón copiar email (verde al copiar) y enlaces a GitHub/LinkedIn con logos
- Botones con hover animado y `prefers-reduced-motion` respetado

## 🛠️ Stack

HTML + CSS + JavaScript vanilla. Tipografía Inter, sin librerías.

## 🚀 Uso

```bash
# clonar
git clone https://github.com/danielruedaaa/portfolio.git
cd portfolio
# abrir
start index.html        # Windows
open index.html         # macOS
```

No hay instalación.

## ✏️ Personalizar

1. Busca `Daniel Rueda` y `daaniel.ruedaa@gmail.com` en `index.html`.
2. Cambia los niveles de las barras en `index.html` (`width:90%` etc.).
3. Sustituye `assets/CurriculumDanielRueda.pdf` y añade `assets/foto.jpg` (180×180 mínimo, cuadrada).
4. Para un proyecto nuevo, duplica un `<article class="juego">` en `#proyectos`.

## 🌍 Publicar

**GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.  
**Netlify / Vercel:** arrastra la carpeta o conecta el repo — sin comando de build.
